Measure Theory & The Poisson Process

1. Foundations: Interpretations & Axioms

Interpretations

  • Classical: Symmetry-based ($N_A/N_{tot}$). Fails for infinite sets.
  • Frequentist: Long-run limit of relative frequency. Fails for single events.
  • Bayesian: Degree of belief. Subjective.
  • Geometric: Ratio of measures (Length/Area).

Axiomatic Resolution

Kolmogorov (1933) resolved inconsistencies by treating probability as a measure with mass 1. It creates a syntax ruleset ($P \ge 0$, $P(\Omega)=1$, Additivity) that supports all interpretations without mandating "what" probability is.

2. Probability vs. Measure Theory

Probability is simply Measure Theory on a normalized space $(\Omega, \mathcal{F}, P)$.

  • Sample Space $\Omega$: The set of all points (analogous to the set $X$ in measure theory).
  • $\sigma$-algebra $\mathcal{F}$: The collection of "measurable" subsets (events). Ensures logical operations (NOT, AND, OR) yield valid events.
  • Random Variable: A measurable function $X: \Omega \to \mathbb{R}$. It maps abstract outcomes to real numbers so that the pre-image of any interval is an event in $\mathcal{F}$.

4. Simulation: The Poisson Limit

We simulate a counting process on interval $T=1$. We divide $T$ into $n$ bins. In each bin of width $\Delta t = 1/n$, a success occurs with prob $p = \lambda/n$. This approximates a continuous arrival process.

Theoretical Mean: 0 Actual Count: 0 Process: Poisson($\lambda$)

5. Analysis of the Process

What process is this?

As $n \to \infty$, this Binomial approximation ($Bin(n, \lambda/n)$) converges to a Poisson Process.

  • Distribution: The total count $N(T)$ follows a Poisson distribution $P(k) = e^{-\lambda T} (\lambda T)^k / k!$.
  • Independent Increments: Events in non-overlapping intervals are independent (by construction of our simulation).
  • Stationary Increments: The prob. of an event depends only on the interval length, not time $t$.
  • Role of $\lambda$: It is the intensity or rate. It represents the average number of events per unit time.
  • Inter-arrival Times: The time between successes converges to an Exponential distribution $Exp(\lambda)$.
