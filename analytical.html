Online Algorithms for Mean and Variance

1. The Problem with "Batch" Algorithms

Traditional "batch" algorithms require the entire dataset to be available before calculation. To find the variance, one must first calculate the mean (first pass), and then iterate through the entire dataset *again* to sum the squared differences from that mean (second pass).

  • Memory-Intensive: They require O(n) memory, as all n data points must be stored.
  • Computationally Inefficient: They require multiple passes over the data.
  • Numerical Instability: A common "single-pass" batch formula, (sum_of_squares / n) - (mean^2), is notoriously unstable. It involves subtracting two very large, similar numbers, which leads to catastrophic cancellation (loss of precision) and can even produce negative variance for data that should have zero variance.

Online algorithms solve this by updating statistics incrementally. They use O(1) memory (storing only the current aggregate statistics) and process each data point only once.

2. Derivation: Recurrence Relation for Mean

We want to find the new mean, mean_n, using only the previous mean, mean_n-1, the new value x_n, and the count n.

1. Definition of mean_n:
mean_n = (1/n) * (x_1 + x_2 + ... + x_n)
2. Separate the n-th term:
mean_n = (1/n) * [ (x_1 + ... + x_n-1) + x_n ]
3. We know that (x_1 + ... + x_n-1) = (n-1) * mean_n-1. Substitute this:
mean_n = (1/n) * [ (n-1) * mean_n-1 + x_n ]
4. Distribute (1/n):
mean_n = ((n-1)/n) * mean_n-1 + (1/n) * x_n
5. Rearrange terms to find the "update" rule. (n-1)/n = (n/n) - (1/n) = 1 - (1/n):
mean_n = (1 - 1/n) * mean_n-1 + (1/n) * x_n
mean_n = mean_n-1 - (1/n) * mean_n-1 + (1/n) * x_n
6. Final Recurrence Relation:
mean_n = mean_n-1 + (1/n) * (x_n - mean_n-1)

This is the simplest form: the new mean is the old mean plus a small adjustment based on the "error" (x_n - mean_n-1) of the new value.

3. Derivation: Recurrence for Variance (Welford's Algorithm)

We use a similar "online" approach for the sum of squared differences from the mean, M2_n. The variance is simply M2_n / (n-1) (for sample variance).

Let M2_n = Sum[ (x_i - mean_n)^2 ] for i=1 to n.

1. Definition of M2_n:
M2_n = Sum[ (x_i - mean_n)^2 ] + (x_n - mean_n)^2 (sum from i=1 to n-1)
2. This is complex because mean_n is different from mean_n-1. Let's use two terms:
delta = x_n - mean_n-1
delta2 = x_n - mean_n
3. From the mean derivation, we know:
mean_n = mean_n-1 + delta / n
delta2 = x_n - (mean_n-1 + delta / n) = (x_n - mean_n-1) - delta / n = delta - delta / n = delta * (1 - 1/n)
→ delta2 = delta * (n-1) / n
4. We also need to update the existing sum terms (x_i - mean_n-1) to use mean_n:
(x_i - mean_n) = (x_i - (mean_n-1 + delta / n)) = (x_i - mean_n-1) - (delta / n)
5. Now, we expand M2_n using this substitution (this is the hardest part):
M2_n = Sum[ ((x_i - mean_n-1) - delta/n)^2 ] + delta2^2 (sum from i=1 to n-1)
M2_n = Sum[ (x_i - mean_n-1)^2 - 2*(delta/n)*(x_i - mean_n-1) + (delta/n)^2 ] + delta2^2
6. Distribute the summation:
Term 1: Sum[ (x_i - mean_n-1)^2 ] → This is exactly M2_n-1.
Term 2: -2*(delta/n) * Sum[ (x_i - mean_n-1) ] → The sum of differences from the mean is 0. This term vanishes.
Term 3: Sum[ (delta/n)^2 ] → This is (n-1) * (delta/n)^2.
7. Combine the terms:
M2_n = M2_n-1 + (n-1) * (delta/n)^2 + delta2^2
Substitute delta2 = delta * (n-1) / n:
M2_n = M2_n-1 + (n-1) * (delta^2 / n^2) + (delta * (n-1) / n)^2
M2_n = M2_n-1 + (n-1) * delta^2 / n^2 + delta^2 * (n-1)^2 / n^2
M2_n = M2_n-1 + (delta^2 / n^2) * [ (n-1) + (n-1)^2 ]
M2_n = M2_n-1 + (delta^2 / n^2) * [ (n-1) * (1 + n - 1) ]
M2_n = M2_n-1 + (delta^2 / n^2) * [ (n-1) * n ]
M2_n = M2_n-1 + delta^2 * (n-1) / n
8. This works! A simpler form uses delta and delta2:
M2_n = M2_n-1 + delta * delta2
(Proof: delta * (delta * (n-1)/n) = delta^2 * (n-1)/n. It matches.)

Final Recurrence Relation:
1. delta = x_n - mean_n-1
2. mean_n = mean_n-1 + delta / n
3. delta2 = x_n - mean_n
4. M2_n = M2_n-1 + delta * delta2
